# Alliance Roofing Solutions website

A responsive business website with dedicated homepage, About and Products pages, built with React, TypeScript, Vite and Tailwind CSS. The product photography is cropped from the supplied Alliance promotional artwork; the industrial scene photos are original generated visuals intended as representative imagery.

## Run locally

```bash
npm install
npm run dev
```

Create a production bundle with `npm run build`, then preview it with `npm run preview`.

The About page is available at `/about.html` and the Products page at `/products.html` while the development server is running. The Products page contains nine editable catalogue placeholders alongside the verified Turbo Ventilator listing.

## Before launch

- Connect the enquiry form to an approved inbox, CRM, WhatsApp flow or backend. Until then, it clearly states that submissions are not sent or stored.
- Add verified company contact details and any approved product specifications, capacity, guarantees or project references.
- Replace the reserved `.example` sitemap host in `public/sitemap.xml` with the real production domain and add the full sitemap URL to `public/robots.txt`.
- Replace the legal placeholder pages with company-approved privacy and terms copy.
- Confirm permission and final selection for representative generated application imagery.
